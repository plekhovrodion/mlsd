# Английский вокруг нас — проверка заданий по фото

Учебный проект курса ML System Design. Ребёнок находит предмет по заданию и фотографирует его. Система проверяет находку и произносит английское слово.

## ДЗ №2

Проведён EDA COCO val2017 и сравнены три предобученные модели на **всех 5 000 изображениях**. Из 58 заданий предварительного каталога 38 имеют соответствие категориям COCO. После отбора классов с минимум 100 положительными фотографиями в сравнении осталось **26 классов**.

Лучший macro AP получил **YOLO11n — 0,821**. При консервативном пороге средний recall по классам составляет **88,4%**, FAR — **4,26%**. У всех 26 классов наблюдаемый FAR ниже 5%. Для рюкзака recall составляет 58,8%, поэтому результаты отдельных заданий рассмотрены дополнительно.

Эксперимент оценивает наличие предмета на открытых размеченных фотографиях. Для проверки в условиях игры запланированы отдельные dev/test, выбор домашнего каталога заданий и интеграция на устройстве. COCO включает бытовые сцены, но репрезентативность для съёмки ребёнком требует отдельной проверки.

Полный прогон выполнен в Kaggle на GPU T4 с Python 3.13.16 и PyTorch 2.11.0+cu130. В репозитории сохранён выполненный ноутбук. Версии пакетов и контрольные суммы весов находятся в `metadata.json`, полный список пакетов — в `requirements-freeze.txt` внутри папки результатов. Разбор ошибок добавлен на CPU по сохранённым score и out-of-fold ответам.

Для повторного запуска откройте ноутбук в Kaggle, включите Internet и GPU T4. Первая ячейка устанавливает закреплённые версии библиотек. Источник данных загружается через KaggleHub. [COCO 2017 на Kaggle](https://www.kaggle.com/datasets/nikitamanaenkov/microsoft-coco-2017)

Полный датасет и веса моделей хранятся отдельно от репозитория. В материалах EDA есть иллюстративные фотографии COCO. Сведения о лицензиях исходного набора сохранены в `licenses.csv`. Все обработанные в ДЗ №2 фотографии взяты из COCO.
