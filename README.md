# Английский вокруг нас — проверка заданий по фото

«Английский вокруг нас» — проект обучающей игры для детей 2–7 лет. Ребёнок получает задание на русском языке, находит нужный предмет дома и фотографирует его. Игра проверяет находку и произносит английское слово, чтобы ребёнок связывал новое слово с реальным предметом и собственным действием.

Для проверки фотографии используется компьютерное зрение. Модель определяет, есть ли в кадре предмет из задания. При правильной находке игра засчитывает ответ, а при затруднении предлагает снять предмет ближе или попробовать другой ракурс.

Игра проектируется для работы в браузере на телефоне или планшете. Взрослый помогает выбрать безопасные задания с предметами, которые доступны дома. Проверка фото планируется на устройстве, с временной обработкой кадра.
