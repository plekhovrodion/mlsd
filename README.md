# Английский вокруг нас — игра с проверкой по фото (2–7 лет)

Учебный проект курса ML System Design.

Ребёнку называют предмет по-русски, он находит его дома или на улице и фотографирует.
Система по фото проверяет, что найден именно нужный предмет, и звучит английское слово.

**Цель:** вовлечь ребёнка и связать английское слово с настоящим предметом.

## Статус

Проект на стадии проектирования (ДЗ №1). Здесь дизайн-документ и каркас для скриптов оценки качества.
Прототип игры (рабочее название кода PhotoQuest: Vite + TypeScript, машина состояний, банк заданий) развивается отдельно.
